# Contributing

Keep this project independently authored and use synthetic inputs. Do not import Antagon proprietary technology or third-party source without clear rights and required attribution. See `docs/IP-BOUNDARIES.md`.

Run formatting, Clippy with warnings denied, and all workspace tests before proposing changes. Protocol changes need updated schema, byte vectors, negative tests, and a versioning decision. Tests must distinguish authenticated claims from observed or corroborated evidence.

This repository is maintained privately during development. Do not change visibility, publish packages, upload generated runtime artifacts, or create public releases without the owner's explicit approval. No contribution license agreement or external governance process has yet been established.

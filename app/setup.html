Replace your passkey

Use this when the passkey is lost, or to move to another passkey. You make the new passkey here. It takes effect only after the administrator of this computer confirms it with the code below. Your account cannot replace the passkey without the administrator.

A passkey can be replaced only when the receiver and the witness run under their own accounts (separate role accounts).

This page computed this code from the passkey that it made. Keep the page open. The administrator runs the command for this computer, exactly as it is here, and types the code. If the command refuses the code, do not continue.

macOS

sudo /usr/bin/python3 -I /private/var/db/openproof/libexec/roles_passkey.py
